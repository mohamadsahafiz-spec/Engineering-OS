# Overview

Cloudflare R2 is an object storage service designed for storing large files rather than structured relational data.

Unlike D1, R2 stores binary objects such as documents, images, videos, backups, and exported reports.

---

# Primary Responsibilities

R2 should own:

- PDF reports
- Images
- Machine screenshots
- Customer attachments
- Backup files
- Exported documents
- Generated assets

R2 should not contain application logic or relational data.

---

# When to Use

Use R2 when:

✓ Large files must be stored

✓ Files need public or controlled access

✓ Reports are generated

✓ Images are uploaded

✓ Backups are required

✓ Storage growth is expected

---

# When NOT to Use

Avoid R2 when:

✗ SQL queries are required

✗ Relational data is required

✗ Configuration storage is needed

✗ Small application settings are stored

Those belong in D1 or KV.

---

# Best Practices

- Organize objects using predictable folder structures.
- Avoid storing application state inside filenames.
- Generate unique object identifiers.
- Protect sensitive files with appropriate access controls.
- Version important assets where practical.

---

# Common Mistakes

- Treating object storage like a database.
- Storing relational data in filenames.
- Exposing sensitive files publicly.
- Ignoring lifecycle planning.
